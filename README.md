# Konjac Translate

Website for **Konjac Translate** — an iPhone translator for travel and work: face-to-face conversation, text translation and your own phrase cards, all translated on the device, even offline.

Served by GitHub Pages at https://sona-orbit.github.io/konjac/

- Home, support and privacy pages in 20 languages (English at the root, others in their own folder)
- Static HTML and CSS, no JavaScript, no build step on this repository
- Contact: sona.orbit.hi@gmail.com
