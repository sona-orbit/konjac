iPhone용 번역 앱

번역 곤약

마주 보고 대화하고, 나만의 문구 카드를 만들고, 모든 번역을 iPhone에서 바로 — 오프라인에서도 가능해요.

App Store에 곧 출시됩니다

iPhone · iOS 18 이상 · 무료 다운로드

1분 만에 살펴보기

실제 iPhone에서 앱을 짧게 둘러보세요.

이런 기능이 있어요

💬

마주 보고 대화하기

화면이 둘로 나뉘고 상대방 쪽은 거꾸로 표시되어, 휴대폰을 사이에 두고 대화할 수 있어요. 말하거나 입력하면 각자 자신의 언어로 번역을 볼 수 있습니다.

  • 기기 내 음성 인식
  • 모든 문장 다시 듣기
  • 번역을 소리 내어 읽기
✍️

텍스트를 번역하고 바로 보여주기

문장을 입력하거나 붙여넣어 번역하세요. 복사하거나 소리로 들려주거나, 큰 전체 화면 카드로 눈앞의 상대에게 보여줄 수 있어요.

  • 복사
  • 읽어 주기
  • 전체 화면 카드
🗂️

나만의 문구 카드

여행이나 업무에서 자주 쓰는 말을 카드로 저장하고, 이름을 붙이고 순서를 바꿀 수 있는 덱으로 정리하세요. 어떤 번역이나 기록도 카드로 저장할 수 있고, 다음에는 선택한 언어로 번역됩니다.

  • 이름을 붙이는 덱
  • 기록에서 저장
  • 기본 여행 카드
바로 쓰는 여행 카드

교통, 식사, 숙박, 쇼핑, 길 찾기까지. 카드를 탭하면 그 자리에서 바로 번역되고, 자주 쓰는 카드는 별표로 표시해 둘 수 있어요.

🕘

기록과 복습

모든 대화와 번역이 iPhone에 날짜별로 정리되어 저장되고, 즐겨찾기도 할 수 있어요. 복습 모드는 기록을 플래시 카드로 바꿔 줍니다.

  • 날짜별 정리
  • 즐겨찾기
  • 플래시 카드 복습(Pro)
📴

기기 내 번역, 오프라인 지원

번역에는 Apple의 기기 내 모델을 사용합니다. 언어를 한 번 다운로드하면 연결 없이도 계속 쓸 수 있고, 말하거나 입력한 내용은 서버로 전송되지 않아요.

  • 약 20개 언어
  • 오프라인 사용
  • 계정 불필요

앱 사용 방법

앱의 실제 화면이에요. 번호는 각 화면 옆 설명과 서로 대응돼요.

1234567

대화

  1. 1상대방 쪽 화면은 뒤집혀 있어서 마주 앉은 사람이 바로 읽을 수 있어요
  2. 2마이크를 눌러 말해 보세요
  3. 3대신 직접 입력하기
  4. 4번역을 다시 들려주기
  5. 5두 언어를 선택하세요. 가운데 화살표를 누르면 방향이 바뀌어요
  6. 6언어를 바꾼 뒤 마지막 문장을 다시 번역하기
  7. 7목록 보기로 전환하기
12345

번역

  1. 1말하고 싶은 내용을 입력하세요
  2. 2번역
  3. 3번역 결과
  4. 4카드로 저장, 소리 내어 읽기, 복사, 전체 화면으로 보기
  5. 5여행 카드와 내 카드 사이를 전환하기
1234

내 카드

  1. 1카드 묶음: 여행, 업무 또는 직접 만든 묶음
  2. 2카드 정리: 순서 변경, 삭제, 이름 변경
  3. 3카드 추가하기
  4. 4카드를 누르면 그 안에서 바로 번역을 볼 수 있어요
12345

복습

  1. 1원문
  2. 2번역, 한 번 누르면 나타나요
  3. 3번역 보기 또는 번역 숨기기
  4. 4이전/다음 카드 (살짝 밀어서 넘길 수도 있어요)
  5. 5무작위 순서

앱 화면 미리보기

무료로 시작하세요

대화와 번역에 필요한 기능은 모두 무료예요. Pro는 나만의 카드를 많이 만들고 싶은 분을 위한 옵션입니다.

무료

  • 마주 보고 대화하기
  • 텍스트 번역 및 전체 화면 카드
  • 기본 여행 카드와 기록
  • 사용자 카드 3개

Pro

  • 사용자 카드와 덱 무제한
  • 기록을 플래시 카드로 복습
  • 독립 개발을 응원하기

주간, 월간 또는 한 번 결제하는 평생 이용권 중에서 선택할 수 있어요. 가격은 App Store에서 현지 통화로 표시됩니다.

내 iPhone에만 보관돼요

  • 번역, 음성 인식, 음성 읽기가 모두 기기 안에서 처리됩니다
  • 계정, 광고, 추적이 없어요
  • 녹음은 절대 저장되지 않아요
  • 기록과 카드는 내 iPhone에만 저장돼요
